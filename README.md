# FishyFacepunch & Facepunch.Steamworks UPM Wrapper

Tired of having to separately install **[FishyFacepunch](https://github.com/FirstGearGames/FishyFacepunch)** & **[Facepunch.Steamworks](https://github.com/Facepunch/Facepunch.Steamworks)** via unitypackage? You can now install them via UPM.

## Dependencies
**[FishNet](https://github.com/FirstGearGames/FishNet)** must be installed in your project first.

## Package Manager git URL
```
https://github.com/briezar/FishyFacepunch.Steamworks.git
```

---

### Bundled Versions
This package explicitly wraps and targets these verified stable versions:
* **FishyFacepunch:** [v4.1.0](https://github.com/FirstGearGames/FishyFacepunch/releases/tag/4.1.0)
* **Facepunch.Steamworks:** [v2.5.2](https://github.com/Facepunch/Facepunch.Steamworks/releases/tag/2.5.2)
